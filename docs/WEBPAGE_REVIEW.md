## 一、当前网页体检：问题清单

### 1. 菜单设计（最痛点）

| # | 问题 | 影响 | 严重度 |
|---|---|---|---|
| 1.1 | 桌面端用 240px 固定左侧栏 `position: fixed` 占满屏幕高度，主内容 `body { margin-left: 220px }` 硬性挤到右侧 | 大屏 / 宽屏阅读区被压缩；打印时仍占 220px | 🔴 高 |
| 1.2 | 侧边栏条目直接以"分类大写标签（WHY/WHAT/...）"开始，与下面的 a 链接无缩进，视觉层级混乱 | 用户难以一眼分辨"组"与"项" | 🟠 中 |
| 1.3 | 红/蓝 `nav-dot` 圆点装饰对实际跳转无价值，反而分散注意力 | 信息密度低 | 🟡 低 |
| 1.4 | 侧边栏条目按编号 00/01/.../34 排序，固定编号限制了未来插入新章节 | 维护成本高 | 🟡 低 |
| 1.5 | "院长汇报 / 渠道培训"过滤 tab 在侧栏顶部，**两层 tab 互相挤占空间** | 用户不知道是"标签"还是"导航" | 🟠 中 |
| 1.6 | 移动端全屏弹出式 overlay 章节靠 `.nav-group` 手风琴展开；展开后无快速跳到同组其他章节的提示 | 移动端需要"展开 → 滚动 → 点击"三步 | 🟠 中 |
| 1.7 | 桌面端"在 hover 时显示 dotPulse 动画" + 移动端 active 态混乱 | 跨端体验不一致 | 🟠 中 |

### 2. 布局与排版

| # | 问题 | 影响 | 严重度 |
|---|---|---|---|
| 2.1 | `body { margin-left: 220px }` 在大屏 (>1440px) 仍固定 220px，未做响应式最大宽度 | 大屏空白浪费 | 🟡 低 |
| 2.2 | 移动端 `body.mobile-page > section:not(.footer):not(.mp-active) { display: none }` ——**一次只看一个章节**，导致"目录"在 back 之前永远是消失的 | 用户迷失位置 | 🟠 中 |
| 2.3 | 章节内文最大宽度 1100px 但 padding 6%，在 1920px 屏幕上左右各 4% ≈ 80px 留白，**没有真正的"黄金分割"留白** | 视觉不够"杂志感" | 🟡 低 |
| 2.4 | 标题 `.section-num` 与 `.section-lead` 字体不区分主次，正文阅读流被打断 | 信息层级不清 | 🟡 低 |
| 2.5 | 大量渐变色背景（深红、深金、墨蓝）用于章节切换，**易造成阅读疲劳** | 培训用文档不适合"重彩" | 🟠 中 |

### 3. 交互

| # | 问题 | 影响 | 严重度 |
|---|---|---|---|
| 3.1 | 桌面端没有键盘可达性：`<a>` 标签无 `aria-label`，无 `tabindex` 自定义；侧栏无"跳转时关闭 overlay"逻辑 | 无障碍不友好 | 🟠 中 |
| 3.2 | 移动端 overlay 通过 `display: none / flex` 切换，**没有动画过渡** | 体验生硬 | 🟡 低 |
| 3.3 | 滚动时侧栏 active 态用 `for (var i = sectionIds.length - 1; i >= 0; i--)` 反向遍历，每次 scroll 都重算 | 性能可接受但应使用 IntersectionObserver | 🟡 低 |
| 3.4 | 二维码弹窗（`#qrModal`）在桌面端定位 absolute，**没有 focus trap** | Tab 键可跳出弹窗 | 🟠 中 |
| 3.5 | 灯箱（`#lbOverlay`）无左右切换键（← / →） | 查看多图不便 | 🟡 低 |
| 3.6 | 搜索功能完全缺失；38 个章节要找特定内容得手动翻 | **大文档最大痛点** | 🔴 高 |
| 3.7 | 没有"返回顶部 / 跳到目录"浮动按钮 | 长滚动无救生圈 | 🟠 中 |
| 3.8 | 打印预览在 `prefers-color-scheme: dark` 时仍打印深色背景 | 浪费墨 | 🟡 低 |

### 4. 内容

| # | 问题 | 影响 | 严重度 |
|---|---|---|---|
| 4.1 | 章节标题大量使用大写英文（"WHY / WHAT / EVIDENCE / ..."）+ 中文小标，对中国渠道商而言"中英混合"是负担 | 学习曲线高 | 🟠 中 |
| 4.2 | 没有"学习路径 / 推荐顺序"，新渠道商不知从哪开始 | 用户迷茫 | 🔴 高 |
| 4.3 | 没有"阅读进度"指示，用户不知道已经看多少 | 成就感缺失 | 🟡 低 |
| 4.4 | "客户画像 / 上海用户名单 / 临床 FAQ"涉及真实医疗机构信息，缺少 disclaimer | 合规风险 | 🔴 高 |
| 4.5 | QR 码指向"完整学术支持包"，但没有具体内容说明 | 用户扫码后预期落差 | 🟠 中 |

### 5. 动效

| # | 问题 | 影响 | 严重度 |
|---|---|---|---|
| 5.1 | 整站动效过于密集：滚动渐入 + 卡片悬停放大 + 数据行左移 + 光晕 + shimmer + 脉冲 + 弹跳…… | **培训手册应冷静专业，不是营销 landing page** | 🟠 中 |
| 5.2 | `dotPulse` / `pulseGlow` 持续动画干扰阅读（动画不停止） | 注意力分散 | 🟠 中 |
| 5.3 | 多个 `setInterval(updateNavMode, 15*60*1000)` 每 15 分钟检查暗色模式——可，但消耗小，不算问题 | 良好 | ✅ |
| 5.4 | 鼠标跟随光晕（`--mx, --my`）需要 JS 监听 mousemove，**在 30+ 卡片时性能一般** | 性能开销 | 🟡 低 |
| 5.5 | CTA 按钮 `pulseGlow` 持续 1.8s infinite，**移动端"一直闪"易触发误触** | 移动端体验 | 🟡 低 |

### 6. 性能 & 资源

| # | 问题 | 影响 | 严重度 |
|---|---|---|---|
| 6.1 | 单文件 970KB，未拆分；首屏在弱网环境慢 | 网络开销 | 🟡 低 |
| 6.2 | 大量重复 CSS（如 `.sidenav.nav-dark` 出现 2 次同样的色块定义） | 维护成本 | 🟡 低 |
| 6.3 | 多处 `onclick="func()"` 内联事件，没有事件委托 | 代码冗余 | 🟡 低 |
| 6.4 | 字体 `Noto Serif SC / Source Han Serif SC / STSong / Georgia / SimSun / PingFang SC / Microsoft YaHei` 七家字体堆叠声明 | 渲染性能 | 🟡 低 |
| 6.5 | 没有任何 `<meta name="description">`，没有 Open Graph | SEO 与分享 | 🟡 低 |

### 7. 可访问性 (A11y)

| # | 问题 | 影响 | 严重度 |
|---|---|---|---|
| 7.1 | hamburger 按钮已有 `aria-label="目录"`，但 overlay 中 `<a>` 没有 | 屏幕阅读器 | 🟠 中 |
| 7.2 | 颜色对比度：`rgba(26,26,26,0.55)` on `#FFF8F5` ≈ 5.0:1，刚好通过 WCAG AA，但偏弱 | 弱视用户 | 🟡 低 |
| 7.3 | 自定义下拉（如未来加）缺少 ARIA `aria-expanded` / `aria-haspopup` | 键盘 + 读屏 | 🟠 中 |
| 7.4 | 章节 `<section>` 没有 `aria-labelledby` 指向标题 id | 读屏无法定位 | 🟡 低 |
| 7.5 | 动画没有 `prefers-reduced-motion: reduce` 降级 | 前庭敏感用户 | 🟠 中 |

## 二、重构方案：顶部主菜单 + 子菜单 + 移动端汉堡按钮

### 2.1 总体设计目标

| 目标 | 落地方式 |
|---|---|
| 桌面端不再被 220px 侧边栏挤压 | 改为顶部 64px 高度 sticky 顶栏，主内容 `body` 不再 `margin-left` |
| 主菜单 / 子菜单清晰分层 | 顶栏一级 8 个分类（WHY/WHAT/EVIDENCE/APPLICATION/DEPARTMENTS/BUSINESS/OMAY/SELL），hover/点击展开下拉面板 |
| 跨端一致 | 桌面 dropdown / 移动端汉堡 → 同一个下拉内容的两种呈现方式 |
| 性能与无障碍 | 改用 IntersectionObserver、CSS `:hover + :focus-within`、ARIA 属性 |
| 克制动效 | 移除"持续脉冲 / dotPulse / shimmer"等干扰性动画；保留 hover 微反馈 |
| 引入搜索 | 顶栏放搜索图标 → 弹层全文搜索（fuse.js 简单版） |
| 引入进度条 / 浮动按钮 | 顶部细条显示阅读进度；右下角"返回顶部 / 回到目录"按钮 |

### 2.4 移动端断点策略

| 断点 | 行为 |
|---|---|
| ≤ 900px | 隐藏分类下拉，**只显示汉堡按钮**；点击汉堡展开全屏菜单（与桌面 dropdown 内容一致） |
| 901–1199px | 顶栏紧凑：分类文字缩写（如 WHY/WHAT/...） |
| ≥ 1200px | 完整分类名称（"WHY 为什么"） |

### 2.5 动效克制化

- 移除 `dotPulse` 持续动画
- 移除 `pulseGlow` infinite 动画，改为一次性 hover 高亮
- 保留 dropdown 淡入（0.18s）+ 轻位移（translateY -4px → 0）
- 保留 `prefers-reduced-motion: reduce` 全部关停
